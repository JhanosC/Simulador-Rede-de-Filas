# Tutorial para Executar o Código

## Pré-requisitos

- Java Development Kit (JDK) instalado no sistema.

## Passos para Execução

1. Compile todos os arquivos Java usando o comando:

   ```
   javac *.java
   ```

2. Execute o simulador com um arquivo (.yml). O arquivo deve seguir o padrão do `model-t1.yml`. Substitua `model-t1.yml` pelo nome do seu arquivo YAML de escolha:
   ```
   java Simulador model-t1.yml
   ```

Certifique-se de que o arquivo YAML esteja na mesma pasta ou forneça o caminho do arquivo desejado.
